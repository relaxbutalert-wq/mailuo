MathPath

MathPath 把数学知识按 依赖关系、关联关系 与 学习路径 组织成一张可探索的知识网络——不只是教材目录，而是看得见「谁先学、谁后学、彼此如何相连」。当前覆盖初一至初三核心内容，未来可平滑扩展到小学、高中与大学。

使用说明

浏览模式（默认）

  • 点击任意节点：右侧查看年级、模块、前置学习链、后续关联与推荐路径。
  • 点击连线：查看所连接的前后知识点（实线＝依赖，虚线＝关联）。
  • 节点下方状态点可标记 未学 / 学习中 / 已掌握，顶栏实时统计完成率。
  • 搜索知识点会自动高亮其完整前置路径并淡化无关节点。

编辑模式

  • 拖动节点调整位置；双击节点文字可修改；选中后拖右下角缩放。
  • 点击连线后出现两端圆点，可拖动调整箭头；滚轮调线宽（Alt+滚轮调箭头大小）。
  • 编辑自动保存在本地浏览器；「导出 → 恢复默认」可还原。

数据与导出

  • 支持导出 PNG / SVG / JSON，导入 JSON 恢复你的版本。
  • 移动端自动切换为「知识树」逐级展开，无需缩放画布。

MathPath · 作品集说明

一、项目背景

MathPath 是一个把数学知识组织成知识网络的产品原型：节点是知识点，边分「依赖（先学后学）」与「关联（横向联系）」两类。它脱胎于「初中数学知识路径图」——之所以重命名，是因为产品早已不止是一张图：它有首页、搜索、筛选、编辑、知识详情与 AI 助教，更像一款教育产品，而非一张流程图。当前覆盖初一至初三，品牌去学段化，未来可平滑扩展到小学、高中与大学。

二、为什么做

市面上的「知识图谱」很多只是教材目录的换皮。我想要的，是能回答「要学会二次函数，我得先补哪些？」的工具——即以学习路径为中心，而非以教材章节为中心。

三、用户是谁

  • 学生：浏览结构、搜索知识点、标记掌握状态、看推荐学习路径。
  • 家长 / 老师：快速理解知识体系，定位薄弱前置。
  • 面试官：一打开即见产品思路与工程实现。

四、核心功能

  • 力导向知识网络布局（非教材列），Bezier 曲线连线。
  • 双模式：浏览（查看 / 搜索 / 路径高亮）与编辑（拖拽 / 改字 / 调箭头）。
  • 知识点搜索 + 前置路径高亮 + 路径发光动画。
  • 掌握状态标记 + 完成率统计。
  • 节点富信息卡（学习时间 / 考试频率 / 掌握程度 / 典型题 / 中考 / 视频 / 文章）。
  • 聊天式 AI 助教（演示模式，可接真实 API）。
  • 导入导出 PNG / SVG / JSON；移动端知识树。

五、技术实现

单文件交付，原生 HTML / SVG / JavaScript，零运行时依赖、零 CDN：

  • 数据驱动：知识以内嵌 JSON 描述（节点 + 带 kind 的连线），渲染与交互全部由数据生成。
  • 力导向布局：轻量弹簧-电荷仿真，按模块聚簇，viewBox 自适应。
  • 状态持久化：localStorage 保存布局、编辑与掌握状态。
  • SVG 序列化导出 PNG / SVG，无需后端。
