使用说明

本工具把初中数学核心知识按年级、模块与前置关系可视化组织，支持浏览查看与编辑两种模式。

浏览模式（默认）

  • 点击任意节点，在右侧查看其年级、模块、前置知识与后续关联；重点节点还含核心内容与常见易错点。
  • 点击连线，可查看它所连接的前后知识点。
  • 顶部搜索框输入知识点，可自动定位并高亮其前置路径，其余节点自动淡化。
  • 左侧可按年级阶段、知识模块筛选聚焦，突出对应区域。
  • 节点不可拖动、文字不可修改——保证知识结构的稳定呈现。

编辑模式（教师 / 教研）

  • 拖动节点调整位置；双击节点文字可直接修改并自动保存。
  • 点击连线后，拖动两端圆点改位置，滚轮调线宽，Alt+滚轮调箭头大小。
  • 选中节点后，拖动右下角小方块可缩放节点尺寸。

数据与导出

  • 编辑结果自动保存在本地浏览器（localStorage），刷新不丢失。
  • 右上角「导出」可导出 PNG 图片、SVG 矢量图、JSON 数据；也可导入自定义 JSON 版本。
  • 「恢复默认版本」可清除本地修改，回到初始知识图谱。

快捷键

  • Shift + Delete：清空本地保存，恢复默认。

项目说明

初中数学知识路径图 · 作品集工程笔记。记录项目背景、用户痛点、产品方案、技术栈，以及测试样例、错误分类、问题归因与迭代记录。

一、项目背景

初中数学知识点多、跨年级关联强，学生常「学了后面忘前面」，难以看清知识依赖关系。传统课件多为静态图，无法交互探索。本项目把初一至初三核心知识按年级、模块、前置关系组织成可交互的知识路径图。

二、用户痛点

  • 知识分散：代数 / 几何 / 概率统计跨三个年级，缺乏统一视图。
  • 依赖不清：不知道某知识点要先学什么、之后连什么。
  • 静态呈现：不能搜索、不能聚焦、不能按自己的理解重组结构。
  • 作品陈旧：原稿为楷体 + 纯红粗箭头的手绘风教研图，不适合作为求职作品集。

三、产品方案（双模式）

  • 学习查看模式（浏览）：浏览知识结构、搜索知识点、查看前置 / 后续、高亮学习路径。
  • 教师编辑模式（编辑）：修改节点、调整位置、编辑关系、保存自定义版本、导出图片或数据。

四、技术栈

• 原生 HTML + 内联 CSS + SVG + 原生 JavaScript（零运行时依赖、零 CDN，可双击离线打开）
• 知识数据内嵌为 <script type="application/json">，页面数据驱动渲染
• localStorage 持久化编辑结果
• jsdom 做自动化冒烟测试（init + 核心交互零报错）

六、错误分类

开发过程中按「现象 → 严重度」归类，共 7 类（A/B 为崩溃级，C/D 为功能缺陷，E 为测试环境限制，F 为体验问题）。

类别类型现象严重度
A初始化崩溃页面加载即抛错：在 null 上调用 addEventListener高
B交互运行时错误切换编辑模式时抛错，功能中断高
C1数据完整性重点节点「实数」缺失核心内容 / 易错点中
C2功能门控过严浏览模式点击连线无效（应显示关系）中
DSVG 渲染箭头 marker 用 innerHTML 注入可能不渲染中
E测试环境限制jsdom 无 scrollTo / canvas，PNG 无法自动测低（非缺陷）
F体验 / 健壮性搜索 / 筛选每次按键弹 toast 干扰低

七、问题归因

每一类错误的根因与对应修复方式。

类别根因修复方式
A元素在 renderGraph() 内重建，但事件在模块顶层（元素为 null 时）绑定，生命周期与作用域错位元素声明提到模块作用域；监听器在 renderGraph() 内、元素存在后再绑定
B模式切换逻辑复制时误用旧变量名 mode，而非事件目标 b.dataset.mode改为 b.dataset.mode
C1人工从约 50 个写死节点抽取 34 个 JSON 时漏写一处 detail补 real-numbers 的 core / commonErrors
C2selectConn 仅 edit 模式生效，浏览态被 early return 拦截改为浏览态展示关系、编辑态才允许调整
DSVG 命名空间下 innerHTML 解析不确定，defs / marker 未进入渲染树改用 createElementNS 创建 marker 并 append
E测试沙箱 jsdom 与真实浏览器 API 差异（scrollTo、canvas、Image）代码加防御（scrollTo 判存在）；PNG 标注浏览器目视验证
F分阶段占位实现未清理，占位提示体验差移除占位 toast，改为实时高亮
