脉络 Mailuo

Interactive Math Knowledge Graph

一个以学习路径为中心的中小学数学知识图谱——把「要学二次函数，我得先补哪些？」变成一张可探索、可对话的知识网络，而非又一份教材目录。

01 · Why

背景与问题

学生学数学最大的痛，不是「某个知识点不会」，而是看不清知识之间的依赖——学了后面忘前面，遇到综合题不知道卡在哪个前置。传统工具解决这个问题的方式，几乎都是错的。

📚
教材是线性的章节顺序 ≠ 认知顺序。学生被迫按目录走，却不知道「二元一次方程组」真正依赖「整式运算」哪一块。
🌊
题库是题海的小猿 / 作业帮解决「这题怎么做」，不解决「我该先学什么」。刷了 100 道，结构还是糊的。
🗺️
图谱是换皮的很多「知识图谱」只是目录可视化。点开仍是罗列，没有「依赖 / 关联」两类边，没有路径推荐。
🎯

核心假设

如果学生能看见知识之间的依赖与关联，能一键高亮「学会 X 所需的前置链」，学习效率会显著不同。产品应以学习路径为中心，而非以教材章节为中心。

👥

用户是谁

  • 学生：浏览结构、搜知识点、标记掌握、看推荐路径。
  • 家长 / 老师：快速理解体系，定位薄弱前置。
  • 面试官：一打开即见产品思路与工程实现。

03 · Design

产品设计与关键决策

六个决策决定了它不是「又一张 SVG」，而是一个有完整交互闭环的教育产品。

1
知识网络，而非教材目录

边分「依赖（先学后学）」与「关联（横向联系）」两类。核心节点普遍连接 4–6 个邻居——函数连方程 / 几何 / 坐标，相似连三角，向量连复数。网络感来自数据，不是装饰。

2
双模式：浏览 vs 编辑

默认浏览（搜索 / 筛选 / 路径高亮）；编辑模式允许拖拽节点、改字、调箭头。状态全部本地保存——降低试用门槛，也方便演示「你的版本」。

3
详情卡即「知识系统」入口

点开节点 = 前置学习链 + 后续关联 + 易错点 + 核心指标（重要程度 ★ / 考试频率 ★ / 常见分值 / 预计学习）。别人一点击就知道：这是知识结构，不是流程图。

4
数据驱动，版本即数据

知识以内嵌 JSON 描述；多教材版本 = 同一依赖网络按版本解析年级与独有节点。新增版本无需改动 SVG，对应作品集里「可平滑扩展」的卖点。

5
AI 是 Tutor，不是按钮

讲解 / 举例 / 出题被统一成一个有上下文记忆的对话：跨节点记住「你刚才在看哪」，能回答「它和刚才那个有什么关系」，不会时回溯前置。接真实 API 只需一个钩子。

6
移动端 = 知识树，不是缩放画布

小屏自动切换为「学段 → 年级 → 模块 → 节点」逐级展开。比把 PC 图谱缩成蚂蚁友好得多。

04 · Tech

技术实现

单文件交付，原生 HTML / SVG / JavaScript，零运行时依赖、零 CDN。可投递、可审计、可离线打开——投递作品集时这点很加分。

🗂 数据驱动架构 DATA

知识以内嵌 JSON 描述（节点 + 带 kind 的连线）。resolveDataset(edition) 按教材版本解析出当前渲染数据；切换版本 = 重解析 + 力导向重排 + 重绘。

🕸 力导向布局 GRAPH

轻量弹簧-电荷仿真，按模块聚簇，viewBox 自适应。约数百次迭代收敛，节点不被重叠、连线不糊成一团。

💾 状态持久化 STATE

localStorage 保存布局、编辑与掌握状态。导出 PNG / SVG / JSON，导入 JSON 还原你的版本——无需任何后端。

🤖 AI Tutor 引擎 AI

aiThreads 每节点独立对话线程；aiLastNode 跨节点记忆；意图路由（为什么 / 例子 / 题 / 对比 / 不会 / 再讲）；回复真实读取图谱关系。预留 window.CZ_AI_ENDPOINT 接真实大模型。

验证方式

用 jsdom 真实加载页面跑 init() 做运行时回归：断言节点 / 边数、模拟点击与跨节点对话、检查打字指示器与线程持久化。零运行时错误才允许上线——比「肉眼看一眼」可靠得多。

05 · Outcome

成果与迭代

从一张硬编码 SVG，成长为有完整交互闭环的教育产品原型。每一轮都对应一个明确的产品 / 工程目标。

🕸

知识网络

59 条横向关联边，核心节点普遍 4–6 连接。依赖边实线、关联边虚线，Obsidian 式网络感。

📚

全学段 + 多版本

小学 → 高中贯通；北师大 / 人教 / 华师大共享同一依赖网络，年级与独有节点按版本差异化。

🤖

连续对话 AI

有跨节点记忆与意图路由的 Tutor，图谱 grounded，可一键接真实 LLM。

v0 原稿单页 SVG 流程图，硬编码节点 + 就近箭头。
Checkpoint A数据驱动重构；现代三栏；首页 / 双模式 / 帮助 / 恢复默认。
Checkpoint B搜索路径高亮、年级模块筛选、导入导出、AI 演示入口。
知识网络升级依赖 / 关联双类型边；力导向；Bezier；详情卡指标；移动端知识树。
Checkpoint C · 全学段 + 多版本扩展至小学 / 高中；MASTER 数据集 + resolveDataset 版本切换。
Checkpoint D · 评审升级关联边翻倍、节点属性 6 宫格、点击涟漪、首页英文副标题与产品特点。
Checkpoint E · AI Tutor三按钮 → 连续上下文 Tutor（跨节点记忆 + 意图路由 + 接 API 钩子）。
